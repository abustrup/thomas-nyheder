# dagens-kompas

**Dagens Kompas** — a daily Danish morning brief (static site on GitHub Pages).

Published by the editorial engine in the private `alexanders-brief-source` repo,
under the `thomas` profile (`BRIEF_PROFILE=thomas`). This repo holds only the
rendered output: `docs/` is the site GitHub Pages serves, `data/` is the archive
of published editions that the rolling weekly/monthly/yearly editions fold.

Nothing here is hand-edited. To change what the brief covers, edit
`profiles/thomas/editorial-profile.md` in the source repo.
